## 6. 判定模型的关键取舍（为什么不是全部标不可判）

本审计对「不可判」采取**不对称**口径，方向不同结果不同，这不是漏洞而是刻意的：

1. **用户没填语言成绩 + 项目要求语言** → 判「差什么」。这是确定的事实（你没这项证明），不依赖仓内有没有登记分数线。
2. **用户填了语言成绩 + 项目没登记分数线** → 判「不可判」。此时说够或不够都是替官方担保，只能请用户去详情页核对。
3. **官方不设可比门槛**（不设分数线 / 资金证明无固定金额 / 无年龄限制）→ 判「不适用」，不占不可判名额。这类条目递交时自证，不构成本人条件与门槛的差距。

若把第 3 条也计入不可判，三样例的不可判率会升到 A 22.0% / B 39.0% / C 43.9%，其中 B、C 越过 1/3 停工线。所以这条口径必须先讲清再谈结论 —— **若 Muse 认为「不设门槛」也应算作「不可判」，本单应停工等裁决**。
