### 5.2 `ie-working-holiday-authorisation` 的 `sources[1]` 有两处问题

```json
{ "type": "secondary", "publisher": "公开资料汇编",
  "url": "https://www.irishimmigration.ie/",
  "claim": "WHA 仅限中国香港（200 名额）、中国台湾（400 名额）及日韩新澳加美等" }
```

1. `publisher` 写「公开资料汇编」，是含糊来源。校验器没拦下，因为 `VAGUE_PUBLISHERS` 只做**精确匹配**（集合里是「公开资料」，不含「公开资料汇编」）。这是真实漏检点。
2. 它标 `secondary`，却引用了与 `sources[0]` 一字不差的官方 URL。要么换成真正支撑这条 claim 的页面，要么合并进 `sources[0]`。
